Nesformer, NES CPU를 Qwen 모델 가중치에 컴파일

Nesformer는 NES CPU를 Qwen3.5 모델 가중치로 표현하는 실험이다. 제작자 설명상 가중치는 학습이 아니라 컴파일러가 계산하며, 모델은 CPU 실행 로그를 토큰 단위로 생성한다. 화면 표시와 컨트롤러 처리는 별도 호스트 프로그램이 담당하므로 콘솔 전체가 신경망 안에 들어갔다는 뜻은 아니다.[3]

Firezone, sans-IO WireGuard 구현 sanstun 발표

Firezone은 WireGuard 상태 머신의 Rust 구현인 sanstun을 발표했다. 공식 글은 병렬 처리에 친화적인 API를 내세우며, 네트워크 입출력뿐 아니라 시간·난수 같은 부수 효과도 상태 로직과 분리하는 sans-IO 설계를 설명한다. 성능·보안 개선은 제작자 설명이며 독립 검증 결과가 아니다.[5]

주목할 이유 · 편집 해석
